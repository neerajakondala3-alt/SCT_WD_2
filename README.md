# 🧮 Calculator Web Application

A simple and responsive calculator web application built using **HTML, CSS, and JavaScript**.  
This calculator supports basic arithmetic operations along with keyboard functionality and real-time calculation preview.

---

## 📌 Project Overview

This project is designed to perform basic mathematical calculations with a clean and modern user interface.  
The calculator is fully responsive and works smoothly on both desktop and mobile devices.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📱 Responsive Design
- ⌨️ Keyboard Support
- 🔄 Real-Time Result Preview
- ❌ Error Handling
- 🧹 Clear & Backspace Functionality
- 💯 Percentage Calculations
- 🎨 Modern UI Design

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
